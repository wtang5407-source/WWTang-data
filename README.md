## 📊 核心项目展示

### 1️⃣ NSCLC临床试验趋势分析 ⭐ 旗舰项目
[![Clinical Trials](https://img.shields.io/badge/ClinicalTrials.gov-2,441%20Records-success?style=flat-square)]()
[![Python](https://img.shields.io/badge/Python-3.10-blue?style=flat-square&logo=python)]()
[![Status](https://img.shields.io/badge/Status-Completed-brightgreen?style=flat-square)]()

**项目简介**：基于ClinicalTrials.gov的2,441项非小细胞肺癌临床试验深度分析，揭示2019-2025年研发趋势与成功率影响因素。

**核心发现**：
- 📉 成功率从2019年63.6%下滑至2025年11.1%
- 🎯 Phase 2/3无缝衔接设计成功率60%（vs 传统32.7%）
- 📈 入组规模与成功率强正相关（>1000人达100%）

**技术亮点**：Pandas数据清洗 | Matplotlib/Seaborn可视化 | 业务洞察提炼

**[📁 查看项目](https://github.com/wtang5407-source/nsclc-clinical-trials-analysis)** | **[📊 分析报告](https://github.com/yourusername/nsclc-clinical-trials-analysis/blob/main/output/reports/business_insights_report.md)**

### 2️⃣ Titanic生存预测：SQL vs Pandas对比分析
[![Kaggle](https://img.shields.io/badge/Kaggle-20C374?style=flat-square&logo=kaggle&logoColor=white)]()
[![SQL](https://img.shields.io/badge/SQL-MySQL-blue?style=flat-square)]()
[![Pandas](https://img.shields.io/badge/Pandas-Data%20Analysis-purple?style=flat-square)]()

**项目简介**：经典Titanic数据集的双轨分析，系统对比SQL与Pandas在数据查询、清洗、分析场景下的优劣。

**对比维度**：
| 场景 | SQL优势 | Pandas优势 |
|:---|:---|:---|
| 数据查询 | 复杂JOIN、窗口函数 | 灵活的链式操作 |
| 数据清洗 | 约束完整性 | 丰富的字符串/时间处理 |
| 探索分析 | 聚合统计高效 | 与可视化无缝衔接 |
| 大数据量 | 数据库优化、索引 | 内存限制，需分块处理 |

**[📁 查看项目](https://github.com/wtang5407-source/titanic-sql-analysis)**
